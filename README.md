## 🧠 What This Project Does

- 📊 Load and preprocess stock price data (CSV / Yahoo Finance API)
- 🧹 Normalize time series data for training
- 🧠 Build and train LSTM model using TensorFlow / Keras
- 📉 Predict future stock prices and visualize results
- 📈 Compare predictions vs actual values with Matplotlib

---

| Tool | Purpose |
|------|---------|

| Matplotlib 📊 | Data visualization |
